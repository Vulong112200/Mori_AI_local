---
Đọc `docs/ROADMAP.md` (và `docs/MODEL_EVALUATION.md` nếu đang ở Phase 0). Không sửa file nào.

Trả lời bằng tiếng Việt, ngắn gọn:
1. **Phase hiện tại** và trạng thái; số task xong / tổng của phase đó.
2. **Blocker**: các task `[!]` kèm lý do; task 🔐 kế tiếp đang chờ người dùng duyệt.
3. **Việc kế tiếp**: task chưa tick đầu tiên (`[ ]` hoặc `[~]`), kèm lệnh/script cần chạy nếu có.
4. **Gate**: tiêu chí gate nào của phase hiện tại còn thiếu.

Nếu `git status` có thay đổi chưa commit, nhắc một dòng.
